# ShopMart — Интернет-магазин на Django

Полнофункциональный интернет-магазин с использованием Django, Bootstrap 5 и AJAX.

## 📋 Характеристики

| Параметр | Значение |
|----------|----------|
| Моделей | 6 (Category, Product, Cart, CartItem, Order, OrderItem) |
| Представлений | 15 (включая 6 AJAX-эндпоинтов) |
| Шаблонов | 8 основных + 2 дополнительных |
| Фронтенд | Bootstrap 5.3 + Bootstrap Icons |
| AJAX | Fetch API (корзина, поиск, оформление заказа) |

## 🚀 Инструкция по запуску

### 1. Создать виртуальное окружение
```bash
python -m venv venv
```

### 2. Активировать виртуальное окружение
```bash
# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Установить зависимости
```bash
pip install -r requirements.txt
```

### 4. Выполнить миграции
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Заполнить базу данных
```bash
python populate_shop.py
```
Скрипт создаст:
- 6 категорий товаров
- 20 товаров с описаниями и ценами
- Суперпользователя: **admin** / **admin123**

### 6. Запустить сервер
```bash
python manage.py runserver
```

## 🌐 Доступ

- **Сайт:** http://127.0.0.1:8000/
- **Админ-панель:** http://127.0.0.1:8000/admin/
- **Логин:** admin / admin123

## 🗃️ Модели

1. **Category** — категория товаров (название, слаг, описание, изображение)
2. **Product** — товар (название, цена, старая цена, остаток, описание)
3. **Cart** — корзина (привязана к сессии)
4. **CartItem** — элемент корзины (товар + количество)
5. **Order** — заказ (данные покупателя, статус, сумма)
6. **OrderItem** — элемент заказа (товар, цена, количество)

## 🔧 Представления (15 views)

### Страницы:
1. `home` — Главная страница
2. `product_list` — Каталог с фильтрацией и сортировкой
3. `product_detail` — Детальная страница товара
4. `category_products` — Товары по категории
5. `view_cart` — Корзина
6. `checkout` — Оформление заказа
7. `order_success` — Подтверждение заказа
8. `user_orders` — История заказов
9. `order_detail` — Детали заказа

### AJAX-эндпоинты:
10. `add_to_cart` — Добавить в корзину
11. `update_cart_item` — Обновить количество
12. `remove_from_cart` — Удалить из корзины
13. `process_order` — Обработка заказа
14. `search_products` — Поиск товаров
15. `api_cart_count` — Количество товаров в корзине

## 🎨 Шаблоны (Bootstrap 5)

1. `base.html` — Базовый шаблон (навигация, поиск, корзина, подвал)
2. `index.html` — Главная (hero, категории, скидки, популярные товары)
3. `product_list.html` — Каталог (фильтры, сортировка, сетка)
4. `product_detail.html` — Товар (описание, количество, похожие)
5. `category.html` — Категория (товары категории)
6. `cart.html` — Корзина (AJAX-обновление)
7. `checkout.html` — Оформление (форма + AJAX)
8. `order_success.html` — Успешный заказ
